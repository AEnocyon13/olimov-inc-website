# OLIMOV株式会社 — コーポレートサイト

日本とウズベキスタンをつなぐナレッジブローカー、OLIMOV株式会社のコーポレートサイト。
Astro による静的サイト。日本語（既定）/ 英語 / ロシア語の3言語。

---

## 未掲載の項目

会社情報は `src/i18n/content.ts` 冒頭の `company` オブジェクトにまとまっています。
住所・メールアドレス・代表者の経歴は実データです。

| 項目 | 状態 | 備考 |
|---|---|---|
| 設立年月日 | 未掲載 | 出典資料になかったため、どこにも書いていません |
| 資本金・従業員数 | 未掲載 | 同上。会社概要に載せる場合は追記が必要 |
| 電話番号 | 未掲載 | 契約書レターヘッドの番号は個人携帯のため、意図的に伏せています |

## 掲載内容の出所と匿名化の方針

本サイトの記載は、以下の社内資料から事実のみを抽出しています。

| 記載箇所 | 出所 |
|---|---|
| 会社名・所在地 | 輸出契約書（EXPORT / SALES AGREEMENT）レターヘッド |
| 実績 01（ポンプ輸出） | 同契約書の建値・決済・準拠法条項、および補修部品発注書 |
| 実績 02（提携仲介） | 提携提案資料および議事録 |
| 実績 03（IT要件定義） | 配送プラットフォーム要件定義資料 |
| 代表プロフィール | 提携提案資料の自己紹介ページ |
| 事業内容の4分類 | 旧サイトの事業説明 |

**取引先の社名はすべて匿名化しています。** 業種・規模・国のみを記載し、
先方の掲載許諾が得られた時点で `content.ts` の `client` を実名に差し替えられる形にしてあります。

**意図的に載せていないもの** — 契約金額、銀行口座情報、買主の詳細住所、
先方担当者名。いずれも非公開の商取引情報です。

## 起動

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/ に静的出力
npm run preview  # ビルド結果を確認
```

Node.js 20 以上が必要です（開発時のみ。出力は純粋な HTML/CSS）。

## デザインシステム

### 地色 — ページ全体で一つ

**背景の反転を一切行いません。** 上から下まで `--paper` 一色で、読んでいる途中に地が
白から黒へ切り替わることがありません。セクションの切れ目は、背景ではなく
**罫線・余白・タイポグラフィ**で表現します。各セクション冒頭の marker 行
（太めの罫 + 朱の点 + ラベル + 件数）がその役割を担っています。

カードだけは地よりわずかに明るい `--surface`（純白）に置いています。
段差は約 4% で、面の切り替わりではなく「わずかな浮き」として読めます。

### 色 — ニュートラル + 1色

無彩色のグレースケールが本体で、朱赤は小さな印としてのみ登場します。
この色は日本の漆・鳥居の朱と、ウズベクのイカット中心にある茜の赤が共有する
唯一の色です。ロゴマークもイカットの菱形（abrbandi）を二つ並べた形——
二つの場所、一つのかたち——から取っています。

| トークン | 値 | 用途 | paper 上の比 |
|---|---|---|---|
| `--paper` | `#F4F4F2` | **唯一の背景色** | — |
| `--surface` | `#FFFFFF` | カード。地より一段だけ明るい | — |
| `--ink` | `#101012` | 本文・見出し | 16.8:1 |
| `--ink-2` | `#45454A` | 副次テキスト | 8.5:1 |
| `--ink-3` | `#5E5E64` | メタ情報・ラベル | 6.0:1 |
| `--rule` | `#D9D9D5` | 通常の罫線 | — |
| `--rule-soft` | `#E6E6E3` | 弱い区切り | — |
| `--rule-strong` | `#B9B9B4` | セクションの区切り | — |
| `--accent` | `#D3391F` | 小さな印と罫のみ | — |
| `--accent-ink` | `#B22C11` | 朱を文字に使う場合 | 5.6:1 |

**アクセント色の使用規則:** 面で塗らず、点・短い罫・矢印の先端など小さな要素に限定します。
文字に使う場合は `--accent-ink`。1画面あたり数箇所までに抑えてください。

### 角丸 — 「操作するものは丸く、構造は角ばる」

ナビのピル、タグ、言語切替などの**操作要素**は `999px` の完全な丸。
カード、パネル、区切りなどの**構造**は角丸なし（0）。この二分をサイト全体で守っています。

### タイポグラフィ

3書体。いずれも日英露を破綻なく組めることを条件に選定しています。

| 役割 | 書体 | 理由 |
|---|---|---|
| 欧文・キリル見出し | **Unbounded** 400–900（可変） | 幅広で角のある幾何学サンセリフ。キリル対応。既視感がない |
| 和文見出し + 全言語の本文 | **Zen Kaku Gothic New** 400/500/900 | 日本語・ラテン・キリルを1書体で担う。900 が見出しに耐える |
| 数値・微細ラベル | **JetBrains Mono** 500 | 契約条件、ルート番号、拠点時刻。等幅で桁がずれない |

和文見出しは Unbounded に和文グリフがないため、`:lang(ja)` で Zen Kaku 900 に切り替えています。

## アニメーション戦略

**3段階のフォールバック。** どの環境でも内容が読めなくなることはありません。

1. **スクロール駆動アニメーション対応**（Chrome / Edge 等）
   `animation-timeline: view()` を使用。コンポジタスレッドで完結するため、
   スクロール中にメインスレッドを一切使いません。JS はゼロ。
2. **未対応**（現時点の Safari / Firefox 等）
   `IntersectionObserver` が `.is-in` を1度付けるだけ。あとは CSS トランジション。
3. **JS 無効**
   `.no-js` が残り、全要素が最初から可視。

`prefers-reduced-motion: reduce` では全アニメーションを `!important` で無効化し、
スタッキングカードも `position: static` に戻します。印刷時も同様に全要素を可視化します。

**リビール要素はビューポートより高くしないこと。** `entry` 基準の範囲は
「要素が入りきったら完了」という意味なので、画面より高い要素は画面内にいる間ずっと
未完成のままになります。大きなブロックを `.rv` で包まないでください。

### 実装上の注意（改変する場合）

- **`animation-range` の終点は `entry` 内に置くこと。** 終点を `cover` に置くと、
  画面内に完全に入っている要素が半透明のまま止まります。文書末尾付近の要素は
  スクロールしきれず永久に完成しません。
- **アニメーションは `transform` と `opacity` のみ。** 幅・高さ・位置は動かしません。
- **矢印や点を端に置くときは transform かオフセットで逃がすこと。** 45度回転させた
  要素は外接矩形が広がり、`scrollWidth` を押し広げて横スクロールを起こします。
- **ヒーローの見出しは1行に収まる長さで書くこと。** 折り返すと行単位のマスク演出が
  崩れ、ファーストビューから軸の図がはみ出します。3言語すべてで確認してください。

## 検証済み項目

| 項目 | 結果 |
|---|---|
| 横スクロール | 375 / 1440px × 日英露 すべてなし |
| テキストコントラスト | 全要素 WCAG AA 適合（違反 0件）。**最も低い箇所でも 5.85:1** |
| タップ領域 | 24×24px 未満の操作要素 0件 |
| 見出し階層 | h1 は1つ、レベル飛ばしなし |
| スクロール到達性 | 文書最下部を含め、画面内のリビール要素はすべて opacity 1（実描画状態で確認） |
| リビール要素の高さ | ビューポートより高いものは 0件（entry 基準の範囲が必ず完走する条件） |
| 背景の連続性 | 全セクションが transparent。全幅を塗る帯は 0件 |
| ヒーロー見出しの折り返し | 日英露いずれも1行に収まることを実測 |
| コンソールエラー | なし |

ロシア語は語長が最も長いため、`overflow-wrap: break-word` と
小画面時のみの `hyphens: auto` を入れています。

## 多言語

`astro.config.mjs` の i18n 設定で `ja` を既定（プレフィックスなし）、`en` / `ru` をサブパスに。
`hreflang` と `x-default` は `Base.astro` が自動出力します。

**ウズベク語の追加を検討する場合:**
1. `src/i18n/content.ts` の `content` に `uz` の辞書を追加し `LANGS` に登録
2. `src/pages/uz/index.astro` を作成
3. `astro.config.mjs` の `locales` に `'uz'` を追加
4. ラテン文字表記であれば既存フォントのまま対応できます
